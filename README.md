# 🪨📄✂️ Rock Paper Scissors

A simple, browser-based Rock Paper Scissors game — playable instantly, no installation needed.

## 🔗 Live Demo

👉 [Play it here](https://karthi248.github.io/RPS-Website/)

## How to Play

- Choose **Rock**, **Paper**, or **Scissors** by clicking a button
- The computer randomly picks its move
- The game automatically shows whether you **Win**, **Lose**, or **Tie**
- Your **Wins / Losses / Ties** score is tracked and saved (even after refreshing the page)
- Hit **Restart** to reset your score back to zero

## Features

- Clean, responsive UI with a themed background image
- Score persistence using `localStorage`
- Instant feedback with win/loss/tie messages
- One-click restart to reset the game
- Simple and lightweight — no external libraries or frameworks

## Tech Used

- **HTML** – structure
- **CSS** – styling, layout, and background
- **JavaScript** – game logic, scoring, and interactivity
