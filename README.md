# 🎮 Rock Paper Scissors

A simple browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## 🔗 Live Demo
[Play it here](https://karthi248.github.io/RPS/)

## Features
- Play Rock, Paper, or Scissors against the computer
- Tracks Wins, Losses, and Ties
- Score saved using localStorage (persists even after refresh)
- Restart button to reset the score

## Tech Used
- HTML
- CSS
- JavaScript

## How to Run Locally
1. Clone or download this repository
2. Open `index.html` in your browser
